Tempest 3000 native integration

The game is Tempest 3000 by Jeff Minter / Llamasoft. The reconstruction uses
function-level ports validated against Nuance; the original executable and
assets are read from the player's disc image. No game image, BIOS, captured
runtime state, or emulator binary is included in this source contribution.

The GPU renderer and collection frontend are John / jedeyesniv-art's work
from Tempest-Collection, integrated with permission. This contribution retains
that project's source and attribution; it does not assign a new blanket license.

Standalone disc_image.cpp / disc_image.h were copied from the collection's
vendored NuanceResurrection fork at collection commit
47bdc7a0e3c12d71ff99258b0e96b55875ed8fe0. They provide ISO/NUZ file access,
not emulated instruction execution. They are the collection's own code (its
.nuz compressed disc support, written for that fork), not Nuance's, so no
Nuance code or license is part of the native Tempest 3000.

stb_vorbis.c: Sean Barrett and contributors, MIT or public domain, at the
recipient's choice. The full license texts and notices are at the end of that
source file. It is used both by the NUZ reader and the launcher's compression
verification. SDL retains its zlib license. The renderer's shaders and all
existing third-party notices remain in their original files.
